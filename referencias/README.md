# Referencias

Material de consulta rápida para el equipo. Godot no importa esta carpeta (`.gdignore`) y no va en el `.exe`.

- `medidas_*.png`: medidas de referencia de las fases.
- `antes-despues/<AAAA-MM-DD>_<tema>/`: el antes y el después de los cambios que alguien pidió ver (regla ARQ-60 de [`ARQUITECTURA.md`](../ARQUITECTURA.md)). Cada carpeta lleva `antes.png`, `despues.png` y una `nota.md` con qué cambió, quién lo pidió y en qué rama.
